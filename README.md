# Social Links Profile

A responsive and personalized social links profile built with HTML and CSS.

This project was inspired by the Frontend Mentor Social Links Profile challenge, but I expanded the original design with my own identity, professional information, social links, icons, animations, and responsive interactions.

## Live Demo

- Live site: https://felipesbelphman-web.github.io/social-links-profile/
- Repository: https://github.com/felipesbelphman-web/social-links-profile

## Overview

The page presents my professional profile as a Junior UI/UX Designer and Front-end Developer based in Dublin, Ireland.

Visitors can access my:

- GitHub
- LinkedIn
- WhatsApp
- Instagram
- Portfolio

## Features

- Responsive layout for desktop and mobile
- Personalized profile information
- Availability indicator
- Custom social media icons
- Smooth hover transitions
- Touch interactions for mobile devices
- Keyboard focus states
- External links opening in a new tab
- Accessible and semantic HTML structure

## Built With

- Semantic HTML5
- CSS3
- Flexbox
- CSS media queries
- Custom local fonts
- Responsive design
- Git and GitHub

## What I Learned

During this project, I practiced:

- Structuring a page with semantic HTML
- Creating reusable CSS classes
- Centering content with Flexbox
- Building responsive layouts with media queries
- Creating different interactions for mouse, keyboard, and touch devices
- Using `:hover`, `:active`, and `:focus-visible`
- Adding smooth transitions between text and icons
- Connecting real social and portfolio links
- Publishing a project with Git and GitHub Pages
